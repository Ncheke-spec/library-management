# Community Library Management System

A simple React library management system for the Web Application Development assignment.

## Features
- Login
- Dashboard
- Add, update and delete books
- Track available book quantity
- Add stock and borrow books
- Transaction history
- Add, update and delete users
- Local Storage
- React Hooks
- React Router

## How to run
1. Open this folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.
